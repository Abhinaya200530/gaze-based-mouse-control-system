# Gaze Based Mouse Control System

A hands-free computer control system that moves the mouse cursor using eye movement, with added voice command support. Built to be a low-cost, accessible option for people who find a traditional mouse and keyboard difficult to use.

## Demo
![Demo](paste-image-here)

## Features
- Eye tracking to move the cursor
- Voice recognition for commands (e.g., click, scroll)
- Works with a standard webcam
- Low-cost and easy to use

## Tech Stack
- Python
- Pandas
- OpenCV
- MediaPipe
- PyAutoGUI
- SpeechRecognition

## How to Run
1. Clone the repo:
   git clone https://github.com/your-username/gaze-based-mouse-control.git
2. Go into the folder:
   cd gaze-based-mouse-control
3. Install dependencies:
   pip install -r requirements.txt
4. Run the project:
   python main.py
